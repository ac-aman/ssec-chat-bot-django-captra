# Django College Assistant Project

This project is a **College Assistant AI (CAPTRA)** built with Django REST framework, LangChain, and Google Gemini API.  
It provides intelligent responses using a **database-driven approach**, helping students, faculty, and visitors with information about departments, faculty, and college activities.

## Features

- AI-powered assistant (CAPTRA) using **LangChain + Google Gemini API**
- Database-driven responses using **SQLite**
- API endpoint for chat integration
- Short, concise, human-like responses
- Intelligent query rewriting
